\section*{Data Availability}

Webis-SR4ALL-26 is available from Zenodo at \href{https://doi.org/10.5281/zenodo.18431942}{\texttt{10.5281/zenodo.18431942}}. The current release contains the file \texttt{sr4all\_full.jsonl}, which stores 301,871 systematic review records in JSON Lines format. Full-text PDFs are not redistributed as part of the archive; where available, source access links are retained in the \texttt{pdf\_url} field.
