# ISSUE-02: Add a schema table to `Data Records`

## What to do

- Add at least one table that documents the main released record schema.
- Show the important fields, their meaning, and their role in the corpus.

## How to do it

- Identify the main record type or types in the release.
- Create a compact manuscript table in `SCIDATA_26_SR4ALL/tables/`.
- Reference the table from `scidata--sr4all-part3.tex`.

## Definition of done

- The manuscript contains a schema-style table for the released records.
- The table is cited from `Data Records`.
- A reviewer can inspect the shape of the data directly in the paper.
