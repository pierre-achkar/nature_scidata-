# ISSUE-18: Add `Author Contributions`

## What to do

- Add an `Author Contributions` section to the Scientific Data manuscript.
- Attribute work in a clear, journal-appropriate way.

## How to do it

- Collect or confirm contribution wording from the co-authors.
- Add the section to the manuscript end matter.
- Keep the style aligned with Scientific Data norms.

## Definition of done

- The manuscript contains `Author Contributions`.
- All listed authors are covered explicitly.
- The wording is ready for co-author confirmation.
