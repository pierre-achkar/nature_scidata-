# ISSUE-30: Run a Scientific Data compliance pass

## What to do

- Run a manuscript-level compliance check against Scientific Data expectations.
- Focus on title, abstract, required sections, figures, tables, and availability statements.

## How to do it

- Compare the draft against `scientific_data_submission_guidelines.md`.
- Use the accepted `SDATA-23-nature-journal` submission as a practical benchmark.
- Record remaining compliance gaps after the pass.

## Definition of done

- A compliance pass has been completed.
- Remaining blockers are documented explicitly.
- The manuscript status is no longer based on assumptions about guideline fit.
